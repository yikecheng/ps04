# Quality benchmark and originality note

## Reference inspected

On 2026-10-15, the public repository `inorrr/can-we-trust-ai-agents` was inspected as a peer-quality reference. The review focused on submission organization, provenance reporting, failure disclosure, publication verification, and technical-demonstration structure.

No source text, topic-specific claims, code, prompts, article prose, visual assets, or generated artifacts were copied. Agent Signal retains its own topic, audience, evidence corpus, selection judgments, arguments, implementation, and voice. The two projects overlap broadly because both concern AI agents, but their editorial questions differ: the reference emphasizes trust and security of tool-using agents, while Agent Signal evaluates production readiness of coding agents for small software teams.

## Transferable lessons adopted

1. Preserve the supplied course `README.md` and `ARCHITECTURE.md` as contracts. Put implementation-specific documentation under `docs/`.
2. Make the grading path explicit with separate architecture, setup, claim-trace, recovery, policy-comparison, second-run, project-status, publication-verification, and demonstration documents.
3. Preserve negative evidence. A policy revision that fails to change a model decision is a result to analyze, not something to rerun until it looks successful.
4. Distinguish direct observation, student report, assistant verification, and unavailable verification in publication records.
5. Use an authored essay voice and production-ready scene structure without weakening evidence boundaries.
6. Keep one status record for completed and pending work so the repository never implies that an unrendered video or unpublished article exists.

## Deliberate differences

- Agent Signal uses an authenticated Codex CLI rather than a metered OpenAI API integration, so dollar cost is unknown and token usage is retained instead.
- Agent Signal's central synthesis is a reversible delegation ladder and a separation between activity, efficiency, and accepted outcomes.
- Its source pool focuses on coding-agent workflow evidence, delivery benchmarks, and small-team operating decisions rather than general agent-security incidents.
- Its real failure history centers on macOS trust roots, broken YouTube feed endpoints, inaccessible full text, and transcript provenance.
